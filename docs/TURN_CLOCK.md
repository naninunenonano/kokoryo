# 持ち時間制 — Ver.0.3.220

各プレイヤー180秒、上限180秒。自分のターン中のみ減り、通常終了・時間切れとも終了時に30秒回復する。
時間切れは未使用ダイスを通常の資源変換処理 `turnClockConvertNormalDie` で変換する。
通常変換と同じ関数なので、基本個数やボーナスの変更を時間切れだけ別途変更する必要はない。
負債はランダム破棄せず、通常手札と命令書から上限超過分をランダム破棄する。
負債のみで超える場合の既存処理と《世界恐慌》の保護を維持する。

## オンライン

- 通常操作は手番本人が行い、状態の提案を HOST に送る。HOST だけが確定状態を配信する。
- 終了は要求／確定方式。参加者側では先にターンを進めない。時間切れも HOST だけが処理する。
- 部屋の対戦ID、ホスト世代、ターン識別子、送信順序、確定版数で重複・古い操作を拒否する。
- 残り時間を1秒ごとに配信。受信側は自端末の単調時計に結び付け、端末間の絶対日時を比較しない。
- HOST は経過時間で判定する。Safari のバックグラウンドで interval が止まっても復帰時に経過分を計上する。
- 終了要求は未確認なら再送し、重複要求には現在の確定状態を再通知する。
- 次の手番の開始時効果は本人が1回実行して共有する。本人が切断して開始しない場合は HOST が時間切れ時に開始・自動解決する。
- 必須のコピー能力／創世記／ユグドラシルの選択途中状態を保存する。未払いの任意選択・支払いは時間切れでキャンセルする。
- ナーロッパランドの他プレイヤーによる選択も HOST が確定する。選択前の古い操作で獲得を巻き戻さない。
- ホスト交代時は新しい世代を発行。前のホストの配信は受け入れない。再接続は確定状態と使用状態を復元する。

既存の Supabase 接続・保存キー・公開 Pages 設定は変更しない。TEST 専用のオンライン禁止設定は含まない。
オンラインの参加者は全員 Ver.0.3.220 以降へ再読み込みし、新規対戦を開始すること。
旧版の進行中対戦は時計情報がないため、自動的には時計付き対戦へ移行しない。

これは既存のブラウザ間 Realtime 構成であり、常時稼働のサーバー時計や不正対策サーバーではない。
全端末（特に HOST）が OS に停止されている間は画面更新・自動終了の配信はできず、再開時に処理する。
ホスト交代時の復元精度は最後に受信した時間情報と通信遅延に依存する。
通信失敗が続く場合は再接続する。新しい接続から現在の HOST の状態を取得する。

## 検証

Node.js 24 で `npm ci --ignore-scripts && npm test`。
出荷する index.html と追加パックを実行する。時計・Bot・カード／雇用回帰のほか、
独立した4つの JSDOM と模擬配送で、時計ずれ、重複、順序逆転、切断、ホスト交代、
再接続、終了競合、終局、ナーロッパランド、支払いキャンセルを検証する。
実 Supabase の複数端末通信・iPhone Safari 実機の代わりにはならない。
GitHub Actions の回帰検査は公開設定や本番データを書き換えない。
